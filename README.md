## 🏗️ 4 Core MEP Disciplines

1. **❄️ HVAC (Heating, Ventilation & Air Conditioning)**:
   - Centrifugal & Screw Chillers, VRF/VRV Systems, Air Handling Units (AHU), Cooling Towers, Duct Sizing, Psychrometrics, and ASHRAE 90.1 / 62.1 standards.
2. **🚰 Plumbing & Piping**:
   - Hydro-Pneumatic Booster Pumps, Water Hammer & Surge Arrestors, PRV Pressure Staging, Gravity & Sump Drainage, STP/WTP, and IPC / UPC standards.
3. **⚡ Electrical & Power Systems**:
   - High-Voltage (11kV/33kV) Transformers, 87T Differential Protection & Harmonic Restraint, DG Sets & Synchronizing Panels, Short Circuit Analysis, and NEC (NFPA 70) / IEC 60364.
4. **🧯 Fire Fighting & Life Safety**:
   - NFPA 13 Wet/Dry Automatic Sprinklers, NFPA 20 Fire Pumps & Jockey Systems, Standpipes & Hydrants, Clean Agent Fire Suppression (FM200 / Novec 1230), and Smoke Evacuation.

## 🚀 Quick Start

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### Installation

```bash
# Clone the repository
git clone https://github.com/shamshadkhan36/FacultyPro.git

# Navigate to project directory
cd FacultyPro

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:5173/` in your browser.
